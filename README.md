# ECON1626 AI Future Forecast

This repository contains the Assignment 3 future forecast essay for ECON1626.

## Repository Contents

- `forecast.html` - the essay in HTML format.
- `README.md` - this overview and navigation guide.

## How to Navigate

Open `forecast.html` in a web browser to read the essay. The file is self-contained and does not require any external dependencies.

## Project Focus

The essay examines how artificial intelligence may reshape work, skills, productivity, and labour market policy over the coming years.
